# Knowledge Motion

先把知识组织清楚，再用动态过程解释它如何运转。默认面向初学者，交付静音视频、知识结构、分镜和独立动画源项目。被委派为知识整理角色时，只完成交接指定的整理职责，返回主 Agent 审核，不递归启动同类整理任务。

## 工作流

1. **研究与定界。** 阅读用户材料；只有主题时先检索可信资料，技术内容优先官方文档与规范。确定本片回答的问题、受众和适用条件，补齐影响核心机制的缺口。阅读 [研究与组织](references/research-and-structure.md)；资料要能支持具体机制节点。
2. **委派知识整理。** 本 Skill 明确请求：宿主支持原生子 Agent 时，将材料包交给独立的知识整理子 Agent。按 [跨宿主交接](references/host-adapters.md) 显式传递任务、材料、约束与产物，不依赖继承全部主对话。等待整理完成，再由主 Agent 检查遗漏、矛盾、关系与模块输入输出。宿主不支持或委派不可用时，由主 Agent 顺序完成同一职责，记录实际模式和原因，不能声称已委派。
3. **保存知识结构。** 按 [数据契约](references/story-contract.md) 生成 `knowledge.json` 与 `knowledge.md`：学习问题、条件、对象、模块和必要子过程、输入输出、包含／先后／依赖／并行／条件关系及节点来源。相关但不影响理解的内容作为扩展，不强加固定层数或模块数量。
4. **编排讲解。** 默认“总览 → 进入模块 → 内部过程 → 回到总览”。阅读 [风格与场景](references/style-and-motion.md)，为每个镜头确定一个主要变化、知识节点、场景、动作阶段与结果。写 `schemaVersion: 2` 的 `story.json` 与 `storyboard.md`。复杂模块可以跨多个镜头；时长分别考虑阅读、动作和结果停留，不平均分配。
5. **制作与验收。** 创建独立源项目，检查章节入口、机制关键状态和镜头交接，修正后渲染、实际播放并核验。结构完成后自动继续；只在重要资料缺失、来源冲突或范围无法确定时询问。

用户指定的受众、尺寸、时长与范围优先。未指定时，按关键关系可读性选择横屏 1920×1080 或竖屏 1080×1920，整片统一画幅；内容决定时长，没有默认 20 秒或 120 秒上限。保持深色视觉、30 fps 和无音轨 MP4。信息过密时拆镜头或重排，不能靠缩小文字塞满画面。

## 创建与渲染

`<skill>` 是本文件所在目录，`<project>` 是调用项目。业务材料、依赖与成片写入调用项目，不写回 Skill 包。

```bash
node <skill>/scripts/create-project.mjs --knowledge <project>/knowledge.json --story <project>/story.json --project-root <project> --out out/knowledge-motion/my-topic
```

脚本校验两个文件及交叉引用，复制完整源模板和内容，生成可读知识稿与分镜。拒绝覆盖已有目录、越出调用项目或输出到 Skill 内。旧分镜须按研究结果重新编排为 v2，不自动机械转换。

在返回的源项目目录运行：

```bash
npm ci
npm run check
npm run preview
npm run render
```

- Node.js 20.19+；首次安装依赖需要网络。需 FFprobe 和 Chromium 系浏览器，可通过 `FFPROBE_PATH`、`REMOTION_BROWSER_EXECUTABLE` 指定本机程序。
- 修改知识或分镜后先运行 `check`，同步可读稿；`preview` 输出关键帧与清单，必须打开图像检查。
- 基础场景包括时序、树构建与合并、并行汇合、条件分支、状态数值、代码／结构／结果联动和分类列表。不能准确表达时，在生成项目中添加自定义 SVG／React 场景，使用同一局部帧与画幅接口；详见数据契约。
- 一切动画由 Remotion 当前帧驱动，预览与导出共用时间轴；不使用真实时钟或 CSS animation 驱动。
- `render` 导出并使用 FFprobe 核验尺寸、帧率、时长、帧数及零音轨，结果写入 `verification.json`。失败时保留源项目并报告实际问题。

## 交付与判断

检查观众能否说清关键对象、动作、原因和结果，而不只认出模块名称。核对具体机制与来源、中文可读性、路径方向、跨镜头对象身份及状态连续性；实际播放成片，媒体规格不能替代内容与视觉检查。

返回可点击的 MP4、知识稿、分镜与源项目入口，说明实际验收及未完成事项。宿主适配和真实运行验证分开表述；只做本地制作，平台发布另按用户授权执行。
