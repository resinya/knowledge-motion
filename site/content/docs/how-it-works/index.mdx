---
title: 从知识到视频
description: 内容提炼、分镜与统一帧时间轴
---

生成过程为：主题或资料 → 短标签与关系 → 布局与分镜 → SVG 关键帧 → 静音 MP4。

Agent 负责理解内容并写出分镜，确定每一步说明什么。脚本验证输入、创建独立源项目，Remotion 按帧绘制 SVG 并导出视频。

所有动画由当前帧计算，包括亮度、路径长度、移动标记、逐字输入和指标数值。预览与成片使用同一个场景组件。

Skill 包只保存通用规则、图标、模板和脚本；每次生成的知识内容、依赖、分镜、源码和成片留在调用项目。

可修改 `story.json` 改内容；修改 `src/Scene.jsx` 或 `src/Glyph.jsx` 扩展画面。改完先运行 check，再检查关键帧。
