---
title: 从知识到视频
description: 研究、知识组织、讲解编排与统一帧时间轴
---

工作流为：资料研究 → 知识结构 → 讲解编排 → 场景预览 → 静音成片。

主 Agent 收集可信资料并确定问题和条件；知识整理子 Agent 接收显式任务与材料包，组织模块、必要子过程、关系与逐节点来源。主 Agent 等待结果，检查遗漏、矛盾和输入输出衔接。不能原生委派时，按同一职责顺序完成并记录实际模式。

知识结构与分镜分别保存。前者描述“要解释什么、依据是什么”；后者描述“先讲什么、用什么场景、发生什么动作”。结构审核后自动进入制作，只在重要缺口、来源冲突或范围无法判断时询问。

创建脚本校验两个内容文件及交叉引用，复制完整模板到独立项目。Remotion 使用当前帧控制场景、路径、报文、树结构和指标，预览与视频共用同一时间轴。所有镜头使用同一画幅，局部帧从镜头起点计算。

可在独立项目修改 `knowledge.json`、`story.json` 和 SVG／React 源码；自定义场景遵循相同接口。修改后先 check，再预览并渲染。Skill 包保存通用规则和模板，项目内容、依赖与成片留在调用目录。

官网部署与平台发布独立于本地视频制作，不由 Skill 自动触发。
