---
title: 分镜与运行参考
description: 三种布局、节点、路径和状态字段
---

必填字段是 `title`、`layout`、`steps`。默认参数为 `duration: 20`、`fps: 30`、`width: 1080`、`height: 1920`；可添加 `kicker`、`subtitle`、`summary` 和资料 `sources`。

每步包含唯一的 `id`、短 `label`、动作 `caption`、完成 `result` 和 `diagram`。可选 `color`、逐字输入 `input`；列表可设置 `badge`。

```json
{
  "id": "pay",
  "label": "下单付款",
  "caption": "付款后通知商家",
  "result": "商家收到已付款订单",
  "diagram": {
    "nodes": [
      {"id":"buyer","label":"买家","icon":"person"},
      {"id":"store","label":"商家","icon":"store"}
    ],
    "edges": [{"from":"buyer","to":"store","label":"付款通知"}]
  }
}
```

以上是一个步骤片段。节点可同时指定 0–1 范围的 `x`、`y`；连线按数组顺序展开和传递对象。

| 布局 | 数量 | 特殊字段 |
| --- | --- | --- |
| list | 2–10 行 | badge；类别配色 |
| grid | 2–6 步 | 可选 input |
| state | 2–8 步 | 顶层 metrics；每步 changes |

state 指标使用 `id`、`label`、`initial`，可选 `prefix`、`suffix`。`changes` 的数字表示该步完成后的绝对值，未提到的指标保持原值。

完整契约与示例位于仓库 `skills/knowledge-motion/references/story-contract.md` 和 `examples/`。

| 命令 | 作用 |
| --- | --- |
| npm run check | 校验分镜并同步 storyboard.md |
| npm run preview | 生成关键帧 PNG |
| npm run render | 导出并核验静音 MP4 |
| npm run verify | 独立核验已有视频 |
