---
title: Knowledge Motion
description: 深色动态信息图与静音知识视频
---

把任意领域的分类、流程或状态变化制作成静音 MP4。画面保留知识全貌，用逐步聚焦、对象传递和结果保留引导视线。

```text
用 $knowledge-motion 制作网购订单从付款到签收的过程，20 秒，输出静音 MP4。
```

默认 9:16、1080×1920、30 fps、20 秒。交付成片、可修改的 Remotion＋SVG 源项目和简要分镜。

| 内容 | 布局 |
| --- | --- |
| 分类与速查 | list：类别配色，逐行聚焦 |
| 连续过程 | grid：步骤卡片，对象沿路径传递 |
| 操作引起的变化 | state：目录、状态与变化记录 |

从[制作指南](/docs/guide)开始，或了解[生成原理](/docs/how-it-works)与[数据契约](/docs/reference)。
