## 安装

当前 checkout 可直接安装完整 Skill：

```bash
npx skills add . --skill knowledge-motion --agent codex --global --copy
```

Claude Code 把 `codex` 改为 `claude-code`；项目安装去掉 `--global`。复制安装时需要完整的 `skills/knowledge-motion/`，包括模板、脚本、锁文件和参考规则。

从远程仓库安装：

```bash
npx skills add resinya/knowledge-motion --skill knowledge-motion --agent codex --global --copy
```

## 给出主题

```text
用 $knowledge-motion 制作“钱去了哪里”，用模拟收支演示余额变化，20 秒。
```

也可以提供知识稿、受众、时长和输出目录。Agent 整理内容、选择布局并编写分镜。

## 用例子直接验证

```bash
node skills/knowledge-motion/scripts/create-project.mjs --story skills/knowledge-motion/examples/shopping.json --project-root . --out out/knowledge-motion/shopping
cd out/knowledge-motion/shopping
npm ci
npm run check
npm run preview
npm run render
```

要求 Node.js 20.19+、FFprobe 和 Chromium 系浏览器。首次安装需要网络。可设置 `REMOTION_BROWSER_EXECUTABLE` 和 `FFPROBE_PATH` 指定本机程序；路径只保存在运行环境中。

先打开预览图，修正画面，再生成成片。视频与源码都保留在调用项目中。
