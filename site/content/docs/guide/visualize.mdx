description: 按知识关系选择画幅、场景与节奏

深色背景、细描边分区、白色短标题和青蓝焦点组成统一视觉语言。总览展示大模块，进入机制后主要空间用于当前过程，当前位置导航仍然可见。对象名称、身份和配色跨镜头保持一致。

| 关系 | 常用场景 |
| --- | --- |
| 双端或多方交互 | 时序图，展示传递方向、内容与收发状态 |
| 结构生成与结合 | 树增长、树合并 |
| 独立处理与依赖 | 并行、汇合、条件分支 |
| 输入与结果的对应 | 代码／结构／结果联动 |
| 分类和数值 | 列表聚焦、操作与连续状态变化 |

基础场景不足时，可在生成项目中编写自定义 SVG／React 场景，沿用统一时间轴、局部帧与画幅接口。

用户指定尺寸优先。未指定时，双端时序、树合并和并排对照优先横屏 1920×1080；单向过程、分类和手机观看优先竖屏 1080×1920。整片统一画幅。

每镜头突出一个主要变化，复杂模块可以拥有多个镜头。分别安排阅读、动作和结果停留时间，不平均分配，也不以统一短时长压缩所有知识。默认交付一条带章节的视频。

描边聚焦、路径展开、对象移动、逐步输入和状态变化都应表达实际含义。回到总览时说明本模块产生什么结果，以及它如何衔接下一模块。
