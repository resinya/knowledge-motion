---
title: 风格与动态过程
description: 用局部动作说明知识如何运转
---

深色背景、细描边分区、白色短标题和青蓝焦点组成统一视觉语言。固定镜头下，整图一直可见。

| 动作 | 表达 |
| --- | --- |
| 描边变亮、背景压暗 | 现在看哪里 |
| 连线逐渐展开 | 关系如何建立 |
| 标记沿路径移动 | 对象从谁传给谁 |
| 文字逐字出现 | 输入或操作发生 |
| 节点、颜色、数值变化 | 操作造成什么结果 |
| 最终状态保留 | 前一步如何衔接后一步 |

流程按“聚焦 → 动作 → 结果 → 保留 → 下一步”演示；分类内容保持类别配色，轮流强调各行。

默认 20 秒：约 1 秒总览、17 秒逐项演示、2 秒完整结果。内容太多时压缩到一个代表场景，优先减少文字。

标题、图标和对象随主题变化。动作应有清楚的起点、终点与意义。
