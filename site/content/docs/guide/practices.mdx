---
title: 预览与验收
description: 分别检查知识、动态画面与媒体规格
---

先检查知识结构：本片的问题与条件是否明确，必要机制是否展开，资料是否支持具体节点，模块输入输出是否衔接，并行和条件关系是否表达正确。

`npm run preview` 输出章节入口、机制关键状态和镜头交接画面；帧号记录在 `previews/manifest.json`。检查中文字体与换行、对象身份、路径方向、状态连续和观看尺寸下的可读性。信息过密先拆镜头或重排，不靠缩小文字解决。

播放成片，确认观众能说出“谁做了什么、为什么、结果是什么”。例如 TCP 三次握手要看清三次报文方向及双方状态变化；浏览器渲染要看见 DOM、CSSOM、样式、布局与绘制怎样演变。仅认出模块名称不算讲清机制。

分类与模拟收支不必强加无意义层级。模拟数字和业务条件需明确标注，不能当作实际记录或所有平台统一流程。

`npm run render` 先输出临时视频，媒体核验成功后生成 `video.mp4`。`verification.json` 记录编码、尺寸、帧率、时长、帧数和音轨数量。媒体规格通过不等于内容和画面通过，仍需实际观看。

源项目保留知识稿、分镜与依赖锁文件，便于修改和复现。失败时说明实际失败项，不报告未完成的检查已通过。
