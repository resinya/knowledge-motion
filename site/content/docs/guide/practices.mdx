---
title: 预览与验收
description: 区分画面检查和媒体规格核验
---

`npm run preview` 生成总览、每步动作中段、完成帧和最终帧；帧号记录在 `previews/manifest.json`。

检查中文字体、文字换行、当前焦点、对象身份、路径方向和完成结果。然后播放成片或密集抽取相邻帧，确认步骤交接与状态持续。

`npm run render` 输出临时视频，核验成功后提升为 `video.mp4`。`verification.json` 记录实际编码、尺寸、帧率、时长、帧数和音轨数量。

通过媒体核验意味着规格满足要求；知识正确性、可读性与动态质量需要实际观看。模拟内容明确标为模拟。

渲染失败时保留源项目，修正后重试。FFprobe 不可用时报告核验未完成。
